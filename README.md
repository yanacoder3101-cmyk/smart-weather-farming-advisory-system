# WeatherWise Pro

## Project Overview
WeatherWise Pro is a web-based weather intelligence platform developed using Python, Flask, HTML, CSS, JavaScript, and OpenWeatherMap API. The application provides real-time weather forecasts, historical weather insights, AI-powered recommendations, farming advisory support, interactive visualizations, and engaging user experiences through weather animations and mini-games.

## Features
- Real-time weather forecasting
- Historical weather data visualization
- Interactive 3D globe visualization
- Voice-based city search using microphone input
- Dynamic weather animations (Rain, Clouds, and Sun)
- Temperature, humidity, wind speed, and pressure monitoring
- Air Quality Index (AQI) monitoring
- Severe weather alerts and notifications
- AI-powered weather suggestions and recommendations
- Location-based weather insights
- Social media weather sharing
- Farming advisory based on weather conditions
- Rain Catcher mini-game for user engagement
- Responsive and user-friendly interface

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Web Speech API (Voice Search)
